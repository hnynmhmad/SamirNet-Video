# SamirNet Video

تطبيق Flutter بواجهة عربية RTL لإدارة الروابط العامة والتعرّف على مصدرها، مع واجهة أولية لمكتبة الوسائط والتنزيلات.

## التقنيات
- Flutter وDart وMaterial 3.
- Riverpod مهيأ لإدارة الاعتماديات.
- اختبار وحدات لتحقق الروابط وتحديد المنصة.
- GitHub Actions للتحليل والاختبار وبناء APK تجريبي.

## التشغيل
ثبّت Flutter stable وAndroid SDK، ثم نفّذ:
```bash
flutter create --platforms=android --org com.samirnet.video .
flutter pub get
flutter analyze
flutter test
flutter run
```

## الحصول على APK
من تبويب **Actions** اختر سير عمل **Android Flutter CI** ثم افتح التشغيل الناجح ونزّل artifact باسم `samirnet-video-debug-apk`. هذا APK تجريبي غير موقّع للنشر.

## محرك الوسائط والقيود الحالية
حاليًا لا يوجد محرك yt-dlp مدمج أو مختبر على Android. تتعرف الشاشة على صيغة الرابط ونطاق المنصة فقط، ولا تدّعي استخراج عنوان أو جودة أو تقدم تنزيل حقيقي. البحث المباشر والتنزيل والمكتبة الدائمة والمشغل وتفاصيل الملف ما زالت تحتاج تنفيذًا واختبارًا. لا يوجد خادم خارجي مطلوب في هذه النسخة.

دمج yt-dlp ليس تلقائيًا على Android؛ فهو يعتمد على Python وملحقاته وقد يتطلب FFmpeg متوافقًا مع ABI. يجب تقييم حزمة محلية قابلة للتوزيع واختبارها على جهاز فعلي قبل تفعيل تنزيلات حقيقية. لا تتجاوز المحتويات الخاصة أو تسجيل الدخول.

## الخصوصية والتراخيص
لا يرفع هذا النموذج روابط أو ملفات إلى خادم تابع للتطبيق. راجع تراخيص Flutter والحزم الخارجية قبل التوزيع. سياسة الخصوصية النهائية ورابط الدعم لم يحددا بعد.

## الاختبارات
تتضمن المستودع اختبارات وحدات لتحديد المنصة والتحقق من الروابط. GitHub Actions يشغّل التحليل والاختبارات والبناء؛ نجاح البناء لا يعني أن تنزيل الوسائط مدعوم.
